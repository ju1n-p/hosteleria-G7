# Hotel Supano

Sitio web del Hotel Supano, ubicado en Tigre Muerto.

## Recorrido

1. `index.html`: portada con imagen principal, reseñas y formulario de contacto.
2. `html1.html`: reservas, precios por noche según cantidad de personas y servicios incluidos
3. `atracciones.html`: actividades y experiencias disponibles

## Ejecutar localmente

Se puede abrir `html/index.html` directamente en el navegador o servir la carpeta con cualquier servidor estático.

```powershell
python -m http.server 8000 --directory html
```

Luego visitar `http://localhost:8000`.
